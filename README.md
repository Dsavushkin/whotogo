# Кто идёт (@whotogobot)

Афиша Москвы и компания на вечер: человек выбирает событие, отмечает «Ищу компанию» и видит, кто ещё идёт.
Чат открывается только при взаимном «Пойдём вместе». На следующий день гости отвечают на вопрос
«С кем хочется увидеться ещё?» — совпадения тоже открывают чат.

Версия 0.2: сайт с входом по почте и паролю (афиша открыта без входа), Telegram-бот и Mini App,
приложение для iPhone, кабинет организатора, загрузка афиши из Timepad.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `app/` | сервер: `api.py` — запросы приложения, `bot.py` — бот, `jobs.py` — фоновые задачи, `sources/timepad.py` — парсер афиши |
| `web/` | Mini App (один HTML, CSS и JS, без сборки), шрифты, тексты соглашения и политики |
| `tests/` | проверки логики: взаимные отметки, чат, блокировки, кабинет организатора |
| `deploy/` | установка на сервер и автообновление |

## Посмотреть на Mac

Двойной клик по `run_local.command`. Откроется `http://localhost:8000` с демо-событиями и людьми.
Это предпросмотр в браузере: бот и Telegram здесь не участвуют.
Чтобы зайти вторым человеком, откройте `http://localhost:8000/?dev=1002` в другом окне.

## Установка на сервер (Ubuntu 22/24)

Одна команда в консоли сервера (под root):

```
apt-get update && apt-get install -y git && git clone https://github.com/Dsavushkin/whotogo /opt/whotogo && bash /opt/whotogo/deploy/install.sh
```

Скрипт спросит токен бота, ваш Telegram ID и токен Timepad, поставит Docker, выпустит https-сертификат
и включит автообновление: каждые 2 минуты сервер сверяется с GitHub и пересобирается, если код изменился.

Если репозиторий снова станет приватным, серверу понадобится ключ: `ssh-keygen -t ed25519 -N "" -f ~/.ssh/whotogo`,
открытую часть добавить в GitHub → Settings → Deploy keys, затем в `/opt/whotogo` выполнить
`git remote set-url origin git@github.com:Dsavushkin/whotogo.git && git config core.sshCommand "ssh -i ~/.ssh/whotogo"`.

Без своего домена адрес будет вида `https://1-2-3-4.sslip.io`. Свой домен: направить его на IP сервера,
вписать в `DOMAIN=` в файле `/opt/whotogo/.env` и выполнить `docker compose up -d`.

## Настройки (`.env` на сервере)

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | Telegram ID администраторов через запятую; свой ID покажет команда `/id` |
| `ADMIN_EMAILS` | почты администраторов сайта через запятую |
| `TELEGRAM_PROXY` | зарубежный прокси для бота, если сервер в России не достаёт до Telegram |
| `TIMEPAD_TOKEN` | токен Timepad; без него афишу наполняют только организаторы |
| `OPERATOR_NAME`, `CONTACT_EMAIL` | подставляются в соглашение и политику |
| `DOMAIN` | адрес сервера |

После правки `.env`: `cd /opt/whotogo && docker compose up -d`.

## Команды бота для администратора

`/stats` — цифры · `/import` — обновить афишу сейчас · `/organizer <tg id>` — открыть кабинет организатора ·
`/ban <id>`, `/unban <id>` · `/hide <id события>` · `/reports` — жалобы.
Любое сообщение боту от пользователя пересылается администраторам.

Для всех: `/login` — одноразовый код для входа вне Telegram. `/quiet` и `/remind` — выключить и включить напоминания перед выходными.

## Приложение для iPhone (`ios/`)

SwiftUI, iOS 17. Экраны: вход по почте и паролю (или по коду из бота), профиль, афиша, событие, «Ищут компанию», «Идёте вместе»,
«С кем хочется увидеться ещё?», чаты. Кабинет организатора остаётся в Telegram.

Запуск: двойной клик по `ios/setup.command` (нужен XcodeGen), затем Run в Xcode.
Адрес сервера задаётся в `ios/KtoIdet/Core/Core.swift`, строка `baseURL`.
